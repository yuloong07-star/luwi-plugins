# 外观 · 深海琉璃 (art 域)

协议第 10.1 节那一档的实物: **不写一行代码**, 一份 `theme/ball.json` + 一组图,
在设置页「浮标外观」那一行里挑一下, 球就换成这套画法。

## 包里有什么

| 在哪 | 是什么 |
| :-- | :-- |
| `plugin.json` | `kind: art`, 零能力零工具 |
| `theme/ball.json` | 六个状态各一张图, 外加 `listening` 的 24 帧脉冲序列 |
| `art/ball-*.png` | 那六张状态图 (240×240 RGBA) |
| `art/listen/frame-00..23.png` | 「正在听」的脉冲帧, 12 fps 循环 |
| `tools/build-art.mjs` | 配色与画法都在里面, 改完重跑一遍 |

## 这套画法长什么样

一颗有体积的玻璃球: 中心透亮、边缘沉下去, 左上一块主高光, 右下一小块反射,
外面套一圈**按状态换色**的光晕 (待机淡蓝、正在听青绿、正在想琥珀、正在说紫、偷看粉、出错红)。
「正在听」那一档用的是帧序列, 光晕一圈圈向外扩再收回, 球体同时轻轻起伏。

## 两条要记住的

1. **多个主题插件可以同时装着, 同一时刻只生效一个** —— 换一个只重画, 不用重装任何东西
2. **读不到就回内置画法**: 插件被删掉 / 目录被手工改坏 / 图缺了一张, 球自己会退回内置那一颗,
   而「换一套外观生效; 删掉插件回退内置」正是这一档的验收判据

## 重新生成素材

```sh
node tools/build-art.mjs
```

零依赖 (PNG 编码是脚本自己写的), Node 18 以上即可, Windows / Linux / 手机上的 node 都能跑。
改配色改 `STATES` 里那几行; 想改成别的状态数、别的尺寸, 改 `SIZE` / `R` / `FRAME_COUNT` 即可。

## 打包与安装

```sh
node ../../tools/lw-plugin-sign.mjs sign --dir plugin --key <你自己的私钥> \
  --out ../../signed --zip ../../signed/art-ball-glass-1.0.0.lwp
```

装完在 Luwi → 设置 → 插件 → **「浮标外观」** 那一行里挑它; 换回"内置画法"也是那一行。
